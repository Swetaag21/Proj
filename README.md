🤖 AI Interview Agent

An AI-powered interview preparation platform that helps users prepare for technical and HR interviews through resume-based questions, interview practice, and intelligent feedback.

🔗 Live Demo: https://proj-680l.onrender.com 

📌 About the Project

AI Interview Agent is a full-stack SaaS-style web application designed to make interview preparation smarter and more accessible.
Users can upload their resumes, generate AI-powered interview questions, practice technical and HR interview rounds, and receive feedback to identify areas for improvement.
The platform also includes Google authentication, a credit-based access system, and Razorpay payment integration for purchasing credits.

✨ Features

📄 Resume Upload: Upload resumes in PDF format.
🤖 AI-Generated Questions: Generate interview questions based on resume details.
💻 Technical Interview Practice: Prepare for technical interviews.
🗣️ HR Interview Practice: Practice common HR interview questions.
📊 Intelligent Feedback: Receive feedback to identify strengths and areas for improvement.
🔐 Google Authentication: Secure sign-in using Firebase Google Authentication.
🪙 Credit-Based System: Manage credits for accessing interview features.
💳 Payment Integration: Purchase credits using Razorpay.
🎨 Modern User Interface: Responsive interface with smooth animations.
🚀 Live Deployment: Access the application online.

🛠️ Tech Stack

Frontend: React.js, Vite, Tailwind CSS, Redux, Framer Motion
Backend: Node.js, Express.js, REST APIs
Database: MongoDB
Authentication: Firebase Google Authentication
Payments: Razorpay
Deployment: Render
